Space Station 14 mapping guide

You need a map or grid file in YAML format and a build from the same game fork. To start from scratch, choose New map….

  • Choose a build and open a map
  • Create a map
  • Save and download a YAML file
  • Fix loading and storage problems

Choose a build and open a map

  1. Download a .yml or .yaml map or grid. Look under Resources/Maps/ in the game repository. On GitHub, download the raw file.
  2. Under Build, select the map’s game fork to load its tiles and entity prototypes.
  3. Click Open file… or drop the file onto the start screen. Check the build before editing: the editor may switch to one that matches more prototypes in the file.

Create a map

  1. Click New map…. Choose a type and build, then name your map.
  2. For a starting floor, choose a tile and set its width and height. Click Create.
  3. Select tiles or entities in the palette and place them on the map.

Save and download a YAML file

Choose File → Save to keep a copy in this browser’s library. Reopen it from Recent in the same browser profile.

Choose File → Download .yml to share the file or add it to your game project. Test it in the same game fork you chose in the editor.

Fix loading and storage problems

  • The file fails to open. Download the raw YAML for a map or grid. You cannot import a GitHub web page or a prototype definition.
  • Tiles or entities are missing. Choose a build with the map’s prototypes. Check the map’s fork and version.
  • The build list is unavailable. Check your connection and reload the page. If the build service is down, try again once it is back.
  • A map disappeared from Recent. Open the browser profile you saved it in. If you cleared the site’s data, open a downloaded copy.
