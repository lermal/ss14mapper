How to edit Space Station 14 maps

Use SS14 Mapper to open a station, shuttle or other Space Station 14 map, or create a new one in your browser.

  • Choose a build and open a map
  • Create a map
  • Save and download a YAML file
  • Troubleshoot an import

Choose a build and open a map

  1. Find a Space Station 14 map or grid saved as a .yml or .yaml file. Game repositories typically keep these maps under Resources/Maps/. If you start on a GitHub file page, download the raw file.
  2. In Build, select the fork the map came from. The build supplies the tiles and entity prototypes the editor uses to display the map.
  3. Choose Open file… and select the map, or drop the file onto the start screen. The editor may choose a different build if it recognizes more of the file’s prototypes. Check the build shown in the editor before making changes.

Create a map

  1. Choose New map… on the start screen. Pick a type, enter a name and confirm the build.
  2. If you want to start with a floor, choose a tile, width and height for it. Click Create.
  3. Use the editor’s palette to place tiles and entities from the chosen build.

Save and download a YAML file

Use File → Save to keep your edits in the editor’s library and reopen the map from Recent in the same browser profile. Use File → Download .yml to export the current map as a file you can share or put into your game project. To test it in-game, use the corresponding fork.

Troubleshoot an import

  • The file fails to open. Check that you downloaded the raw map or grid YAML. A repository’s web page and other YAML files, such as prototype definitions, are different file types.
  • Tiles or entities are missing. Check the selected build against the fork and version that produced the map. The build may lack prototypes used by the file.
  • The build list is unavailable. Reload the editor when your connection and the build service are available.
  • A map disappeared from Recent. Check the browser profile where you saved it. If that site data was cleared, open a downloaded copy.
