Выбрать сборку и открыть карту

  1. Скачайте карту или грид в формате .yml или .yaml. Ищите карты в папке Resources/Maps/ репозитория игры. На GitHub скачайте исходный файл.
  2. В поле Сборка выберите форк, для которого создана карта. Так вы загрузите его тайлы и прототипы объектов.
  3. Нажмите Открыть файл… или перетащите файл на стартовый экран. Перед редактированием проверьте сборку: редактор может переключить её на ту, в которой нашёл больше прототипов из карты.

Создать карту

  1. Нажмите Новая карта…. Выберите тип и сборку, укажите название.
  2. Чтобы добавить пол, оставьте флажок Пол, выберите тайл и задайте ширину и высоту. Для пустой карты снимите флажок. Нажмите Создать.
  3. Выберите тайл или объект в палитре и нажмите на место для него на карте.

Сохранить карту и скачать YAML

Нажмите Файл → Сохранить, чтобы оставить копию в библиотеке браузера. Откройте её из списка Недавние в том же профиле браузера.

Нажмите Файл → Скачать .yml, чтобы передать файл другому человеку или добавить его в проект игры. Проверяйте карту в том форке, который выбрали в редакторе.

Решить проблемы с загрузкой и сохранением

  • Файл не открывается. Проверьте, что вы скачали YAML карты или грида. HTML-страницу GitHub и YAML с описанием прототипа нельзя открыть как карту.
  • Не хватает тайлов или объектов. Сверьте форк и версию карты с выбранной сборкой. Выберите сборку, в которой есть нужные прототипы.
  • Список сборок не загружается. Проверьте подключение к интернету и обновите страницу. Если сервис сборок недоступен, дождитесь восстановления его работы.
  • Карта пропала из списка «Недавние». Откройте профиль браузера, в котором вы сохранили карту. Если вы удалили данные сайта, откройте скачанную копию.
